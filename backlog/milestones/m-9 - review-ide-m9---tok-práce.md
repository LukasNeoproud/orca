## Description

Od tiketu po vydání: jednotka práce (větev, tiket z Jiry, pull request, vydání podle tagů) a její fáze; přehled Moje práce, odznaky a oznámení na ploše pro větev bez pull requestu, review, které trvá dlouho, čekající opravy po review a sloučenou práci bez vydaného buildu; tiket z Jiry se stavem práce a odkazem na pull request na stránce Tasks. Zařazeno před zbytek M2 (rozhodnutí uživatele 2026-11-24, decision-16). Mimo milník: zápis do Jiry, připomenutí reviewerovi, oznámení na telefon, stav buildu z pipeline.
